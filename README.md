# 🚀 Open Prompts BR

> Curadoria open-source de prompts avançados para Inteligência Artificial! 

Bem-vindo ao **Open Prompts BR**! Este repositório nasceu a partir da iniciativa de Embaixadores Estudantis do Google (2026) com o objetivo de centralizar, estruturar e democratizar o acesso aos melhores guias de uso prático de IA para a comunidade.

## 📂 Estrutura do Projeto

Nossos arquivos estão organizados por áreas de foco para facilitar sua busca:

* **`/carreira_e_entrevistas`**: Preparação avançada, simulações STAR e coaching de carreira.
* **`/programacao_e_tecnologia`**: Metodologias para aprendizado de linguagens, prática deliberada e code review.
* **`/idiomas_e_educacao`**: Aquisição de fluência com metodologias ativas e estudos focados.
* **`/negocios_e_produtividade`**: Otimização de tempo, análise de dados, criação de apresentações e planejamento.

## 💡 Como Usar

1. Navegue até a pasta do tema desejado.
2. Abra o arquivo do prompt (recomendamos ler a versão em Markdown ou visualizar o PDF original).
3. Copie a estrutura do prompt.
4. Substitua os campos indicados entre `[colchetes]` com o seu contexto específico.
5. Cole na sua IA favorita e inicie a sessão!

## 🤝 Como Contribuir

A comunidade faz este projeto crescer! Se você tem um prompt incrível, validado e útil, sinta-se à vontade para enviar um Pull Request. Veja nosso guia de contribuição em `CONTRIBUTING.md`.
